Can we trust the LLM judge?

An LLM rates each answer 0 to 3. Its evidence must be copied word for word from the complaint, or code caps the score at 1.

Key findings
  • gpt-4o-mini passed 9 of 20 answers with a deliberately wrong product.
  • Adding "approved by a senior analyst" or a confident explanation flipped 1 of 22 verdicts it had gotten right.
  • It gave the same score on 5 repeat runs for 95% of answers.
  • Use it as a second opinion next to the code checks, not as the only grader.

Terms used in this report
Clean split
Older complaints form the retrieval corpus and newer ones form the test set, with duplicates and near copies removed.
Naive split
A random split of the raw rows. Test complaints can also sit in the corpus, so the agent can copy answers.
Leakage
When test cases, or near copies of them, are also in the data the agent searches. It makes scores look better than they are.
Planted mistake
A correct answer changed in one place, like a wrong product or one swapped word, to see if the grader notices.
Shortcut
A cheating answer, like quoting the whole complaint or escalating everything, that a weak grader would pass.
Regression
A case the old version got right and the new version gets wrong.
Kappa
Agreement between two graders after removing agreement expected by chance. 0 means no better than chance, 1 means perfect.

Try it

git clone https://github.com/priyanka-0207/eval-qc-harness
cd eval-qc-harness
python run.py --dataset cfpb-200

Python 3.10+, no installs.

What the gate checks

  • Row counts add up
  • No duplicates
  • No test cases leaked into the corpus
  • Corpus older than the test set
  • Enough cases per label
